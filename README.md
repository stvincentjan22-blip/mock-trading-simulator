# 가상화폐 · 주식 실시간 모의 투자 시뮬레이터
> **Real-time Mock Trading Simulator with Live Matching Engine & Valuation Tracking**

업비트(Upbit) 공개 WebSocket을 통한 **24시간 실시간 가상화폐 시세**와 국내/해외 대표 주식의 **실시간 틱/호가 시뮬레이션**을 기반으로, 실제 증권사/거래소와 동일한 방식으로 모의 체결 및 실시간 평가손익을 산출하는 풀스택 모의 투자 시뮬레이터입니다.

---

## 🌟 핵심 구현 기능

### 1. 실시간 시세 기반 모의 체결 엔진 (Matching Engine)
- **시장가 주문 (MARKET)**: 최우선 호가(매수 시 최우선 매도호가, 매도 시 최우선 매수호가)로 즉시 100% 체결 및 잔고/보유량 반영.
- **지정가 주문 (LIMIT)**:
  - 매수 지정가: 현재 시장 매도호가/체결가가 사용자의 지정가 이하로 내려오는 순간 즉시 체결 및 잔여 슬리피지 환불.
  - 매도 지정가: 현재 시장 매수호가/체결가가 사용자의 지정가 이상으로 올라오는 순간 즉시 체결.
  - 미체결 상태(`PENDING`) 동안 예수금 또는 보유 수량을 안전하게 잠금(Locking)하여 초과 주문 방지.
  - 미체결 주문 원클릭 취소 시 예약 예수금 100% 즉시 환불.
- **수수료 시뮬레이션**:
  - 가상화폐: 0.05% (업비트 KRW 마켓 기준)
  - 주식: 0.015% (국내 증권사 모의 기준)

### 2. 실시간 평가손익 및 수익률 연동 (Live PnL Engine)
- WebSocket으로 수신되는 모든 틱(Tick)마다 다음 지표를 실시간 계산 및 화면에 브로드캐스트:
  - **보유 종목별 평가금액**: $\text{보유수량} \times \text{현재가}$
  - **보유 종목별 평가손익**: $\text{평가금액} - (\text{보유수량} \times \text{평균매수가})$
  - **보유 종목별 수익률**: $\frac{\text{현재가} - \text{평균매수가}}{\text{평균매수가}} \times 100\%$
  - **총 자산**: $\text{예수금} + \text{미체결 예약금} + \sum \text{종목별 평가금액}$
  - **총 평가손익 & 누적 수익률**: 초기 자본금 1억 원 대비 실시간 등락률 반영
  - 한국 거래소 스타일 컬러 반영 (상승/수익: 빨강, 하락/손실: 파랑) 및 가격 변동 틱 플래시 효과

### 3. 실시간 시세 피드 (Market Feed Hub)
- **가상화폐**: `wss://api.upbit.com/websocket/v1` 실시간 연동 (인증키 불필요).
  - 지원 종목: 비트코인(KRW-BTC), 이더리움(KRW-ETH), 솔라나(KRW-SOL), 리플(KRW-XRP), 도지코인(KRW-DOGE).
- **국내 주식**: 네이버 금융(Naver Finance) 공식 실시간 시세 연동 (2초 폴링 & KRX 실시간 틱/호가 엔진).
  - 지원 종목: 삼성전자(005930), SK하이닉스(000660), 현대차(005380), NAVER(035420), 카카오(035720), LG에너지솔루션(373220), 삼성바이오로직스(207940), POSCO홀딩스(005490), 셀트리온(068270), 기아(000270), 에코프로비엠(247540), KODEX 미국S&P500(379800).

### 4. 전문 트레이딩 터미널 UI (Dark Theme Pro Dashboard)
- **차트**: TradingView Lightweight Charts 탑재 (실시간 1분봉 캔들 자동 갱신).
- **호가창(Order Book)**: 실시간 매도 5호가, 매수 5호가 및 볼륨 뎁스 바 표시. 호가 행 클릭 시 주문 가격 자동 입력.
- **주문 패드**: 시장가/지정가, 매수/매도 전환, 10% / 25% / 50% / 100% 빠른 수량 계산 버튼.
- **보유 자산 탭**: 보유 종목 리스트, 실시간 손익, **원클릭 시장가 전량 청산** 기능.
- **미체결 주문 탭**: 대기 중인 지정가 주문 목록 및 원클릭 취소.
- **체결 내역 탭**: 최근 체결 로그 및 실현손익 기록.
- **계좌 초기화**: 언제든 1억 원 기본 계좌로 초기화 가능.

## 📁 프로젝트 구조

```
mock-trading-simulator/
├── backend/
│   ├── models.py            # Pydantic 데이터 모델 (주문, 포트폴리오, 캔들)

│   ├── matching_engine.py   # 모의 체결 엔진 (지정가/시장가 매칭, PnL 계산)
│   ├── market_feed.py       # 업비트 웹소켓 + 주식 실시간 피드 허브
│   └── main.py              # FastAPI 서버, WebSocket 엔드포인트 및 정적 서빙
├── frontend/
│   ├── index.html           # 반응형 다크모드 트레이딩 터미널 HTML
│   ├── styles.css           # 거래소 스타일 CSS (애니메이션, 뎁스 바, 플래시)
│   └── app.js               # WebSocket 통신, 차트 제어, 실시간 평가손익 렌더러
├── tests/
│   ├── test_trading_engine.py  # 체결 로직, 수수료, 평가손익 단위 테스트
│   └── test_api_endpoints.py   # REST API 및 데이터 파이프라인 통합 테스트
├── run.py                   # 서버 단독 실행 스크립트
└── README.md                # 시스템 명세서
```

## 🚀 실행 방법

### 1. 패키지 설치 (최초 1회)
```bash
py -m pip install fastapi uvicorn websockets httpx
```

### 2. 서버 실행
프로젝트 루트 디렉터리에서 아래 명령을 실행합니다:
```bash
py run.py
```

### 3. 브라우저 접속
웹 브라우저를 열고 접속합니다:
👉 **http://127.0.0.1:8000**

## 🧪 테스트 실행
체결 엔진 및 API 테스트를 다음 명령어로 검증할 수 있습니다:
```bash
py -m unittest discover tests
```
